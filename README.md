# MACHINE LEARNING ZOOMCAMP

This repository documents my journey through **DataTalksClub's Machine Learning Zoomcamp**.

The goal is not just to complete the course, but to understand the concepts deeply, implement them through the weekly lessons and homework, and apply what I learn to a real-world AI/ML system.

## What This Repository Contains

**Lessons & Notes** — concepts learned throughout the course
* **Homework** — weekly hands-on assignments
**Experiments** — practical implementations and experiments
**Capstone** — an evolving real-world ML project
**Metrics** — dedicated notes and implementations for ML evaluation
**Research** — papers, references, and related research
**Learning in Public** — weekly reflections and project updates

## Learning Approach

Each lesson follows this cycle:

**Learn → Implement → Complete Homework → Document → Apply → Evaluate → Share**

The capstone will evolve throughout the course as new ML concepts are learned and applied.

> This repository is primarily a learning record. The final applied project will eventually be extracted into its own dedicated repository.
